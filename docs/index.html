1Install the plugin

You need XIVLauncher with Dalamud. Konnyaku Jelly lives in its own plugin repository, so add that first.

  1. In game, type /xlsettings and open the Experimental tab.
  2. Under Custom Plugin Repositories, paste this link: 
    https://raw.githubusercontent.com/gnomerock/konyakku/main/repo.json
  3. Tick Enabled, click +, then Save and Close.
  4. Type /xlplugins, go to All Plugins, search for Konnyaku Jelly and click Install.
Updates are automatic. Once the repository is added, Dalamud offers new versions in /xlplugins like any other plugin.

Using your ChatGPT subscription

Install Node.js, then run this once in a terminal (PowerShell is fine):

npm i -g @openai/codex
codex login   # choose "Sign in with ChatGPT"

The settings window then shows "ChatGPT login found. You're good to go!"

Using an API key

Paste your key into the API key box. Models are listed cheapest first. The cheapest one is chosen for you and is plenty for chat.

Check it works

Keep the window open while you play. To save tokens, chat is only translated while the window is open. Turn this off in Settings → Chat if you want everything translated all the time.

4Read chat

Messages from the channels you picked appear in the Chat tab, already translated.

  • Each line shows a coloured channel badge, the sender and the time.
  • The translation is in white, and the original is underneath in blue-grey.
  • Right-click a line to copy the translation.
  • Messages already in your language are skipped, so they cost nothing.
Which channels? Say, Party, Alliance, FC, Tells, Novice Network, LS and CWLS are on by default. Shout and Yell are off, because busy cities would burn through your quota. Change them in Settings → Chat.

5Write chat

Type in your own language and it goes out translated.

  1. Pick a channel from the To dropdown. The right side shows which language it will be sent in.
  2. For a Tell, also type who it's for, like Mochi Mochi@Tonberry.
  3. Type your message and press Enter or Send.
  4. Not sure about it? Click Copy instead. It's translated and copied to your clipboard, but not sent.

6Translate pasted text

For anything outside chat: a Lodestone post, a Discord message, a website.

  1. Open the Paste tab.
  2. Paste the Japanese text with Ctrl+V, or click Paste.
  3. Click Translate to English. Use Copy to grab the result.

8Commands

Handy for macros, and for chatting without opening the window.

CommandWhat it does
/jellyOpen the Konnyaku Jelly window
/jelly <text>Translate into your outgoing language and copy it to the clipboard
/jelly /p <text>Translate and send to party right away. /s, /fc, /a, /l1, /cwl1 and /t Name@World work too
/konyakkuShow or hide the window
/konyakku configOpen settings

Macro example

/jelly /p Thanks for the run, everyone! See you next time o/

?Help

Most problems are one of these.

The window says "Something went wrong"

Open settings and click Test connection to see the full error. With the ChatGPT subscription, run codex login again. With an API key, check the key and that your account has credit.

Nothing is being translated

Check that the window is open, that the checkbox at the top of the window is ticked, and that the channel is ticked in Settings → Chat. Messages already in your reading language are skipped on purpose.

How much does it cost with an API key?

Very little. A chat line is a couple of hundred tokens, so a thousand messages costs cents on the cheapest models. To keep it low, leave Shout and Yell off, keep "only translate while the window is open" on, and use the default (cheapest) model. Identical messages are only translated once.

Is my API key safe?

It's stored in plain text in your Dalamud plugin config on your PC, and only sent to the provider you chose. Don't share your config file.

Which languages are supported?

English and Japanese for now.
