1Install the plugin

You need XIVLauncher with Dalamud. Konnyaku Jelly is listed in Gnomod, gnomerock's plugin repository, so add that first. It also gives you any other Gnomod plugins.

  1. In game, type /xlsettings and open the Experimental tab.
  2. Under Custom Plugin Repositories, paste this link: 
    https://raw.githubusercontent.com/gnomerock/Gnomod/main/repo.json
  3. Tick Enabled, click +, then Save and Close.
  4. Type /xlplugins, go to All Plugins, search for Konnyaku Jelly and click Install.
Updates are automatic. Once the repository is added, Dalamud offers new versions in /xlplugins like any other plugin.

Using your ChatGPT subscription

Install Node.js, then run this once in a terminal (PowerShell is fine):

npm i -g @openai/codex
codex login   # choose "Sign in with ChatGPT"

The settings window then shows "ChatGPT login found. You're good to go!"

Using an API key

Paste your key into the API key box. Models are listed cheapest first. The cheapest one is chosen for you and is plenty for chat.

The Jelly tab

A small vertical Jelly tab sits on the left edge of the screen. Click it and the window slides out from that edge like a drawer. Close the window (✕) and the tab comes back. Drag the tab (it wobbles like jelly) along the left or right edge to move it, or drag it out onto the screen and it turns into a normal window where you drop it. Drag that window against a screen edge and let go to dock it as a drawer again. In Settings → Look you can turn the tab off, put it back on the left edge, or turn off the drawer.

Keep the window open while you play. To save tokens, chat is only translated while the window is open. Turn this off in Settings → Chat if you want everything translated all the time.

4Read chat

Messages from the channels you picked appear on the Chat page, already translated.

  • Each line shows a coloured channel badge, the sender and the time.
  • The translation is in white, and the original is underneath in blue-grey.
  • Right-click a line to copy the translation.
  • Messages already in your language are skipped, so they cost nothing.
Which channels? Only Party (including cross-world party) and Alliance are on by default, for raiding. Tick FC, Tells, LS or others in Settings → Chat if you want them. Be careful with Shout and Yell: busy cities burn through your quota.

5Write chat

Type in your own language and it goes out translated.

  1. Pick a channel from the To dropdown. The right side shows which language it will be sent in.
  2. For a Tell, also type who it's for, like Mochi Mochi@Tonberry.
  3. Type your message and press Enter or Send.
  4. Not sure about it? Click Copy instead. It's translated and copied to your clipboard, but not sent.

From the game's own chat box

A small blue translate button sits just right of the game's chat input. Type your message there as usual (a channel command like /p at the start is fine), then click the button. Your text is replaced with the translation; press Enter to send it. Turn it off in Settings → Chat.

6Translate pasted text

For anything outside chat: a Lodestone post, a Discord message, a website.

  1. Click Paste in the sidebar.
  2. Paste the Japanese text with Ctrl+V, or click Paste.
  3. Click Translate to English. Use Copy to grab the result.

8Commands

Handy for macros, and for chatting without opening the window.

CommandWhat it does
/jellyShow or hide the Konnyaku Jelly window
/jelly <text>Translate into your outgoing language and copy it to the clipboard
/jelly /p <text>Translate and send to party right away. /s, /fc, /a, /l1, /cwl1 and /t Name@World work too

Macro example

/jelly /p Thanks for the run, everyone! See you next time o/

9Settings tour

Settings has five tabs.

Translator

Pick the provider, model and key. Test connection checks it all works.

Languages

Chat I read (English, Japanese or Thai) and Messages I send (English or Japanese). The Custom prompt starts as "Used in FFXIV online communication and raiding contexts." Add your own rules after it, for example:

Keep 'gg' and 'o/' as-is. Use casual Japanese.

Chat

  • Only translate while the window is open
  • Skip your own messages
  • Show the original text
  • Also echo translations into game chat ([Jelly])
  • Translate button next to the game's chat box
  • Which channels to translate

Words

Japanese messages are sent to the AI with the meanings of the FFXIV words in them (散開 = spread, 消化 = farm …), from a shared glossary and your own My words list. Your meaning wins for the same word.

Collecting words is off by default. If you agree, the plugin keeps a list of FFXIV words (散開, 消化, 野良 …) that the AI spots in Japanese chat you receive on public channels (Say, Shout, Yell, Party, Alliance, Novice Network, Party Finder), each with its meaning. It never keeps what you type, whole messages, names or times, never reads Tells, FC or linkshells, and the list stays on your PC.

Share sends the words you tick to the shared glossary, after showing you exactly what goes out: each word, its meaning, and a random install ID. Words that several players share are reviewed and added for everyone.

Look

The blue & white theme (turn it off to use your Dalamud style) and how many lines the log keeps.

?Help

Most problems are one of these.

The window says "Something went wrong"

Open settings and click Test connection to see the full error. With the ChatGPT subscription, run codex login again. With an API key, check the key and that your account has credit.

Nothing is being translated

Check that the window is open, that the checkbox at the top of the window is ticked, and that the channel is ticked in Settings → Chat. Messages already in your reading language are skipped on purpose.

How much does it cost with an API key?

Very little. A chat line is a couple of hundred tokens, so a thousand messages costs cents on the cheapest models. To keep it low, leave Shout and Yell off, keep "only translate while the window is open" on, and use the default (cheapest) model. Identical messages are only translated once.

Is my API key safe?

It's stored in plain text in your Dalamud plugin config on your PC, and only sent to the provider you chose. Don't share your config file.

Which languages are supported?

English and Japanese both ways. Chat you read can also be translated into Thai. Thai shows in the Konnyaku Jelly window, but isn't echoed into game chat because the game's font has no Thai letters.
